# Escrow/payments: start deferred until a dedicated planning session

**Context.** The waiting-period plan proposed the escrow POC (P0) as parallel
filler work while admin and Azure decisions pend.

**Decision.** Dre directive: NO escrow or payment work begins, including P0
sandbox exploration, until a dedicated planning session. Recorded as a START
DEFERRED banner on Wave 4 in the plan file so it is never picked up as filler.

**Why.** Money paths deserve deliberate planning, not opportunistic scheduling;
starting "just the POC" creates momentum and half-formed interfaces before the
fee model (D6), provider choice, and alarm prerequisites (I3/STD 7) are settled.

**Revisit when.** Dre convenes the escrow planning session; its output unlocks
P0 with D6 inputs.
