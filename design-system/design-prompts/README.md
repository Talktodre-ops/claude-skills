# design-prompts

A skill for writing design prompts for Claude Design (or any AI design tool), distilled from the prompts we wrote for Heimly.

- `SKILL.md`: when to use it, the workflow, and the prompt template.
- `knowledge/prompt-structure.md`: section order, what each section holds, how constraints are worded.
- `knowledge/design-rules.md`: reusable layout, type, colour, component, data, form, navigation, motion and writing rules.
- `knowledge/dos-and-donts.md`: one-line dos and don'ts with the reason and the source prompt.
- `knowledge/states-and-edge-cases.md`: checklist of states and edge cases every screen prompt covers.
- `knowledge/review-checklist.md`: how to check a returned design element by element.
- `knowledge/heimly-specifics.md`: Heimly brand, colours, tone, market context and vocabulary. The only Heimly-specific file.
